KHAN BIRYANI CENTRE — WEBSITE
================================

FILES
- index.html: website structure
- assets/style.css: responsive visual design
- assets/script.js: menu, cart, WhatsApp order and table reservation interactions

HOW TO PUBLISH ON GITHUB PAGES
1. Create a new GitHub repository.
2. Extract this ZIP file.
3. Upload index.html and the assets folder to the repository root (not inside another nested folder).
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select main branch and /(root), then Save.
7. Wait for GitHub Pages to publish the site.

FUNCTIONS INCLUDED
- Responsive restaurant landing page
- Menu categories and search
- Portion selection and cart quantity controls
- Order summary sent to WhatsApp
- Table reservation modal with guest count, date and selectable time slots
- Reservation request sent to WhatsApp
- Click-to-call and Google Maps directions
- Free delivery message (up to 3 km, minimum order ₹300)

IMPORTANT
This is a front-end website. Online ordering and reservation requests are sent to the restaurant WhatsApp number +91 87509 62292 for manual confirmation. It does not process online payments, maintain live table inventory, or create confirmed orders automatically. For live payments, order management, admin dashboard, SMS/WhatsApp API automation or real-time table availability, connect a backend and payment gateway.

MENU TRANSCRIPTION NOTE
Menu and prices were transcribed from the photos supplied in chat. Please verify them with the restaurant before publishing. The current website uses the menu prices from the clearer blue/white menu photo where possible. Beverage prices are from the same photo.
Business address and phone are based on the Google Maps details shared in the conversation.
